# JSON anidado hostil revienta la pila en seis puntos de entrada

## Problema

Un texto JSON con anidamiento muy profundo (p. ej. `'{"a": ' + "[" * 20_000`, unos 40 KB, por
debajo de cualquier límite de tamaño) hace que `json.loads` / `JSONDecoder.raw_decode` lancen
`RecursionError`. La validación de propuestas (`politica.desde_json`) ya se protegió contra
esto, pero el mismo agujero sigue abierto en todos los demás sitios que parsean JSON de origen
hostil (telemetría, salida de modelo, log en disco). Allí el `RecursionError` sale crudo y tumba
el ciclo entero en vez de seguir el contrato de error de cada punto.

## Comportamiento esperado

Ningún punto de entrada deja escapar `RecursionError` (ni otra excepción ajena a su contrato).
Cada uno trata el anidado hostil igual que ya trata una entrada ilegible:

- **`guardia.eventos.cargar`**: la línea hostil se salta con constancia; las líneas válidas se
  cargan. El motivo registrado en `corpus.saltadas` debe contener la palabra `anidado`.
- **`guardia.transporte.extraer_json(texto)`**: con anidado hostil devuelve el texto **tal cual**
  (sin modificar), para que la validación de destino lo rechace.
- **Triaje con LLM** (`Triaje(...).proponer(incidente)`): ante una respuesta hostil del modelo
  devuelve `None` y queda auditado el evento existente `triaje_descartado`.
- **`EvaluadorAdversarial(...).evaluar(propuesta)`**: la respuesta hostil de una lente se trata
  como respuesta ilegible (no es objeción); el dictamen resulta `limpio`.
- **Generador**: una línea hostil en la respuesta del modelo se ignora como cualquier línea que no
  es un evento; la generación no revienta y la admisión decide con lo que queda (con solo esa
  línea, `generacion.admision.admitido` es falso).
- **`guardia.auditoria.Auditoria`**: una línea hostil añadida a mano al fichero del log hace que
  `verificar()` devuelva un veredicto con `intacta == False` (la lectura la trata como
  `CadenaRota`), en vez de morir.

Un JSON legítimo del sistema anida pocos niveles (3 como mucho); los corchetes o llaves dentro de
cadenas JSON no cuentan como anidamiento y no deben provocar rechazos.

## Interfaz que debe existir

Todo existe ya; no cambia ninguna firma:
- `guardia.transporte.extraer_json(texto: str) -> str` (importable desde `guardia.transporte`).
- `guardia.eventos.cargar(ruta)` -> `Corpus` con `len(corpus)` y `corpus.saltadas`.
- `Auditoria.ruta`, `Auditoria.registrar`, `Auditoria.verificar().intacta`.
- Evento de auditoría `triaje_descartado`; `Dictamen.limpio`; `generacion.admision.admitido`.

## Fuera de alcance

- Cambiar el límite de tamaño o la gramática de propuestas.
- Cambiar los contratos de error existentes de cada punto de entrada.
